# FortiPi Worker

The Worker hosts the ControlPlane, AgentSession and WorkspaceObject authorities. `WorkspaceProxy` comes from Cloudflare Computer; Linux execution uses the real container host. Public requests use the generated contract catalog. Internal authority paths are inaccessible through the public router.

AgentSession composes the pinned PiHarness, Lifecycle and WebSockets capabilities. Pi and application records share the queued Durable Object SQLite adapter. Lifecycle owns alarms; Pi owns task execution. The JSON stream disables the capability RPC protocol and rejects Cap'n Web upgrades before acceptance.

An admission reserves infrastructure capacity and persists its operation, message and task identities before submitting to Pi. Retries recover the original receipt. Cancellation records a durable intent; it does not promise rollback. Uncertain execution preserves its original assignment and queries that execution with an exact retained Workspace renewal observation. Success requires committed result evidence and a durable application event.

The selected model comes from the persisted Agent configuration through an authenticated private ControlPlane fetch after readiness. Factory startup performs no ControlPlane network call or OAuth refresh. API-key bindings and the ControlPlane OAuth delegate remain separate from application and executor credentials. Model usage budgets are not implemented.

Pi reads the complete current Models registry through its supported dynamic accessor, keeping credential resolution with the registry that created each provider. A bounded nonsecret catalog and indexed outstanding admission/allocation configurations restore required providers after process replacement. A provider authentication-mode change conflicts while outstanding work needs an incompatible configuration. Environment keys never select a model or provider implicitly.

One actor controller bounds every installed provider and the public Models handoff:256KiB encoded message/event and queued bytes,64KiB tool arguments,16,384 raw events,60 seconds and32MiB cumulative encoded work per stream. Contiguous deltas of the same kind and index batch at4KiB or100ms; start/end/tool boundaries and all content are preserved. The original12–20-byte and explicit256-byte100KiB progress cases pass locally. Concurrent provider lanes share the configured infrastructure admission limit across registry replacements, and cancellation retains a lane until the provider's public result settles. These are infrastructure limits, with no provider token, spend or weekly budget. An admitted Pi run permits four tool rounds; its normal retained-input continuation remains available after the turn limit.

Each new model admission durably claims a prospective estimate derived from existing completion headroom (32MiB under Free defaults), plus input and metadata estimates, before model/capacity work. Admission compares public SQLite size with all unspent local estimates in the shared queue. Estimates remain charged through unknown outcomes and consumed settlement until a real queued physical observation is acknowledged by ControlPlane. A definitive Pi busy/idle rejection retains its identity and actual unused/0 settlement proof through the same observation barrier before reclaiming the local estimate. Changed request payloads conflict. These are estimates, not physical upper bounds.

Conversation creation also persists identity and pending growth before model selection or capacity calls. Forks estimate copied public Pi history in bounded pages, retaining their cursor and an actual object high-water mark before reserving the final estimate. These values do not measure a future child or promise a physical upper bound. Hard infrastructure holds remain held; declared retry windows are preserved before returning an error. Explicit matching retries keep the original identity. Resume waits for the preceding settlement ACK and samples reclaimable growth before claiming another model operation.

The router's physical ControlPlane calls depend on the route owner. Every authenticated JSON route first calls `authenticate`. Agent and Workspace routes also register the actual recipient before calling it. Control-owned JSON routes call `handleApi` directly after authentication; they do not register an unrelated Agent or add another router authorization call. Streams go directly to ControlPlane's atomic ticket redemption and query-free forwarding. Control-owned byte routes currently authenticate in the router and again in the separate owner fetch; both physical calls count.

Physical storage samples use ordinary admission, including the Agent submit/job phases and Workspace freshness work. Exhausted ordinary admission holds new growth; samples cannot consume retained-completion repair headroom. Active queries coalesce with lease renewal rather than polling every five seconds. One actual Free principal-pressure case preserves an admitted native job's query, renewal, lease-update delivery, facts, result delivery, receipt and terminal closure with the sampler integration. Cloud and paid-backend pressure remain separate acceptance gates. Executor byte requests still make two physical CP admissions; the ongoing materialization now reuses validated identical content within its existing snapshot-byte bound.

The generated catalog currently has74 operations. The five assigned-job snapshot/upload operations require the executor audience and forward to ControlPlane.fetch. Native pending consent projects an exact operation-bound local-policy wait; allowed preparation clears that wait without claiming a running process. The Agent rejects delayed phase regression using its durable job version. Local qualification includes a file-bearing Computer snapshot through native execution, Workspace CAS, receipt and terminal confirmation. The unchanged31-file/same-content Free preparation now starts one process in18.79s with one blob GET, compared with138.97s/33 attempts before reuse. These are local end-to-end fixture results, not a cloud latency guarantee.

Agent exports retain immutable bounded NDJSON with supported committed Pi entries, canonical messages and allowlisted public task/job/approval records. The descriptor reports the actual Agent and retained conversations, measured byte length and SHA-256. Private peer copying requires the retained logical export/backup action and exact snapshot scope. Public downloads separately require administrator `artifacts.read`. Exports exclude credential, provider-auth and socket-authority records and do not reclaim storage.

Free defaults limit each retained artifact to1MiB. Export growth is claimed before reservation; one copy lane bounds working memory per Agent. Ready descriptors require actual retained bytes. They remain readable under current authority while settlement is delayed or a wake marker cannot be written. Existing Lifecycle repair closes the original bookkeeping debt; its ACK and a later physical sample are both required before retiring growth. No settlement RPC runs in the copy lane or the known-descriptor path.

Use the repository's pinned toolchain and normal frozen installation. Focused checks are:

```sh

node --test apps/worker/test/{agent,execution,models,api}/*.test.ts
```

The abrupt-recovery tests launch real local Wrangler processes with `--persist-to`, kill workerd with `SIGKILL`, and reopen the same state. In-process Wrangler fixtures do not prove persistence. Faux model tests establish orchestration behavior; they do not establish live Workers AI, external-provider, native-filesystem or paid-backend qualification.
